# MJ Assistant - Muse

Module Foundry VTT `mj-assistant`.

## Installation

Dans Foundry : **Modules** → **Installer** → coller ce lien dans « URL du manifeste » :

```
https://github.com/cedrictorres0427-ops/fvtt-module-mj-assistant/releases/latest/download/module.json
```

## Publier une nouvelle version

1. Augmenter `version` dans `module.json` et remplacer la version dans `download`.
2. Commit, puis tag `v<version>` poussé sur GitHub : l'action « Release » construit le zip et la release.
